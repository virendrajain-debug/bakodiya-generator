# Bakodiya Generator House --- Website Requirements

## 1. Project Overview

Build a professional, fast, SEO-focused business website for:

**Bakodiya Generator House**\
**Location:** Shahpur, Betul, Madhya Pradesh, India

The website is for a generator sales/business client. The primary goal
is **local discovery, trust, product visibility, and direct enquiries**.

This is NOT a large e-commerce website. It should be a compact,
polished, highly usable **4--5 page business website** with a strong
local SEO foundation.

### Core business information supplied by the client

-   Business name: **Bakodiya Generator House**
-   Location: **Shahpur, Betul, Madhya Pradesh**
-   Generator capacity range: **10 kVA to 500 kVA**
-   Brands mentioned by client:
    -   Kirloskar
    -   Mahindra
    -   Eicher
    -   Ashok Leyland
    -   Escorts
-   Client statement: they keep original generators from the listed
    companies.
-   Generator configurations:
    -   Canopy / silent-type enclosed generators
    -   Open generators / generators without canopy
-   Instagram:
    -   https://www.instagram.com/bakodiya_generator_house/
-   Google Maps location supplied by client:
    -   https://maps.app.goo.gl/5AwCZr5yzHzyepgPA?g_st=aw

### Important content rule

Do not invent: - phone numbers - WhatsApp numbers - email addresses -
GST number - certifications - dealership/authorization claims - years in
business - customer reviews - prices - exact product specifications -

# 3. Design Direction

## Mandatory design style

Use a **LIGHT THEME ONLY**.

Do NOT create: - dark mode - black futuristic UI - neon cyberpunk
styling - excessive gradients - gaming-style interface -
glassmorphism-heavy interface - excessive animations

The visual direction should be:

**Industrial + Professional + Clean + Local Business + Trustworthy**

Think of a premium generator/equipment company website, not a technology
startup.

## Visual language

Use: - white backgrounds - warm/light neutral sections - strong dark
text - one restrained accent color - clean cards - subtle borders -
realistic product photography - generous spacing - strong typography -
clear CTA buttons - simple icons

The website should look excellent on both desktop and mobile.

## Typography

Use a professional modern sans-serif font.

Possible choices: - Inter - Manrope - DM Sans - Poppins

Do not use more than 2 font families.

## Important autoplay requirement

The client wants reels to autoplay.

For **locally hosted MP4 videos**, implement:

``` html
<video
  autoplay
  muted
  loop
  playsinline
  preload="metadata"
  poster="..."
>
  <source src="..." type="video/mp4">
</video>
```

Autoplay MUST be muted.

Do not depend on audio autoplay.

## Instagram limitation

Instagram embeds/reel URLs cannot always be made to autoplay like a
normal HTML5 `<video>` because Instagram controls the embedded player
and browser autoplay policies.

Therefore implement two modes:

### Preferred mode

Client provides/downloads approved reel videos as MP4 files.

Store them locally, for example:

`/public/reels/reel-01.mp4`

Use native HTML5 video with muted autoplay.

### Fallback mode

If only Instagram URLs are supplied: - show a polished reel card - use
thumbnail/poster - include "Watch on Instagram" - open the reel on
Instagram - optionally use an Instagram embed if appropriate

Never fake an autoplaying Instagram player.

# 28. IMPORTANT SEO + VERCEL NOTE

Vercel itself does NOT automatically guarantee SEO.

SEO depends on how the site is built.

Therefore:

-   Use real page routes.
-   Ensure page HTML contains meaningful content.
-   Ensure titles/descriptions are rendered correctly.
-   Ensure headings are semantic.
-   Ensure sitemap exists.
-   Ensure robots.txt exists.
-   Ensure canonical URLs exist.
-   Ensure structured data exists.
-   Ensure pages are crawlable.
-   Avoid making the entire site depend on JavaScript rendering when
    possible.

If using Next.js, use proper metadata APIs and static pages.

If using plain HTML, create actual HTML pages.

Do NOT build an SEO-hostile single-page application where all page
content only appears after JavaScript executes.
